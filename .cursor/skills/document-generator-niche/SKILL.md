# Document generator niche

- Never copy third-party contract templates; write original clause explainers.
- Set `isLegalAdjacent: true` and show the legal banner in `DocumentGenerator`.
- Cite FTC, SBA, HUD, Copyright Office, CDC overview links where relevant.
- Not legal/medical advice disclaimers on consent and contract pages.
