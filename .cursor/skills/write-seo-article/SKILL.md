# Write a guide

1. Add entry to `src/data/guides.ts` (answerFirst, sections, FAQ, relatedToolSlugs).
2. Page auto-generates at `/guides/[slug]/`.
3. 800–1200 words, one H1, cited sources, link to 2+ tools.
4. Add Article JSON-LD via existing `guides/[slug].astro` template.
